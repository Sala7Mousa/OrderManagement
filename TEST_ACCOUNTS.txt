## Apply the Seed Migration

Run the following command from the solution directory:

```powershell
dotnet ef database update `
  --project src/OrderManagement.Infrastructure `
  --startup-project src/OrderManagement.Api
```

## Login

Send a `POST` request to `/api/auth/login`.

Administrator request:

```json
{
  "email": "admin@example.com",
  "password": "Admin123!"
}
```

Customer request:

```json
{
  "email": "customer@example.com",
  "password": "Customer123!"
}
```

Copy the returned JWT and send it with protected requests using:

```text
Authorization: Bearer <token>
```

Do not use these credentials in production.
